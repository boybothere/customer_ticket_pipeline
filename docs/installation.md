# Installation

## Stable release

To install Customer Ticket Ingestion Pipeline, run this command in your terminal:

```sh
uv add customer_ticket_pipeline
```

Or if you prefer to use `pip`:

```sh
pip install customer_ticket_pipeline
```

## From source

The source files for Customer Ticket Ingestion Pipeline can be downloaded from the [Github repo](https://github.com/boybothere/customer_ticket_pipeline).

You can either clone the public repository:

```sh
git clone https://github.com/boybothere/customer_ticket_pipeline
```

Or download the [tarball](https://github.com/boybothere/customer_ticket_pipeline/tarball/main):

```sh
curl -OJL https://github.com/boybothere/customer_ticket_pipeline/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd customer_ticket_pipeline
uv sync
```
